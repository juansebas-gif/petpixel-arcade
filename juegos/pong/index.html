Ficha Técnica & Base de Datos de Trampas

Pong: Impossible invierte la convención del juego justo: la inteligencia artificial tiene licencia para romper cualquier regla cuando va perdiendo o para burlarse del jugador.

🃏 30 Trampas Coleccionables por Rareza

Rareza Frecuencia Ejemplos de Trampas
Común Frecuente Teletransporte instantáneo, Raqueta Gigante, Empujón Sónico, Bola Fantasma.
Poco Común Media Inversión de Controles, Gravedad Invertida, Espejismo de Raquetas, Pelota Curva.
Rara Baja Lanzamiento de Bombas, Red Láser, Mini-Agujero Negro, Escudo Electromagnético.
Extrema Crítica Multibola Caótica x5, Congelamiento Temporal, Clonación de IA, Robo de Punto.

* Cada vez que el bot activa una trampa nueva durante la partida, queda registrada permanentemente en la Base de Trampas del menú inicial del juego.

⚙️ Especificaciones del Motor

Tecnología HTML5 Canvas 2D, Vanilla JavaScript (IIFE encapsulado)
Sistema de Audio Web Audio API procedural (Cero archivos .mp3/.wav externos)
Bucle de Cuadros 60 FPS con Delta-Time acotado (1ms - 33ms)
Efectos Visuales Filtro CRT Scanlines, viñeta perimetral y resplandores neón
Resolución Base 960 × 540 px (16:9) con ajuste responsivo dinámico
Persistencia LocalStorage integrado para récord y colección de trampas
Aislamiento Iframe hermético que previene interferencias de teclado o estilos
